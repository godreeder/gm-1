# ГМ · Последняя дверь

Играбельная версия 0.7.0 визуальной новеллы для вертикального экрана и Telegram Mini App. Статический HTML/CSS/JavaScript, без сборки и платных API.

## Что работает

- Выбор главного героя: Коля, Макс, Ваня или Ярик; семь глав, ключевые сюжетные развилки и пять финалов.
- Романтические и дружеские решения. Максу доступны только девушки. Счастливый общий финал доступен без романа.
- 131 изображение: 28 фонов, 17 спрайтов и состояний, 86 сюжетных иллюстраций.
- Постепенное появление текста, журнал, досье, улики, галерея, настройки, необязательный атмосферный звук.
- Автосохранение, три ручных слота, экспорт и импорт файла.
- Интеграция с Telegram: разворот приложения, кнопка «Назад», безопасные отступы, облачное автосохранение при поддержке клиента.

Основной сезон проходим от начала до конца. Это первая игровая адаптация сценария: используются ключевые диалоги и личные сцены, а не каждая строка расширенного литературного файла. Озвучки и лицевой анимации нет. Работа облака требует проверки внутри реального Telegram Mini App; локально проверено сохранение на устройстве.

## Запустить на компьютере

Из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173. Не запускайте index.html через file:// — загрузка сценария требует HTTP. Для проверки логики при установленном Node.js: `npm test`. Зависимости устанавливать не нужно.

Нажатие на сцену сначала завершает печать реплики, затем продолжает историю. На компьютере доступны пробел и стрелка вправо. Решения выбираются отдельными кнопками.

## GitHub Pages

1. Создайте репозиторий GitHub. Для бесплатного Pages обычно нужен публичный репозиторий: сценарий и изображения станут общедоступны.
2. Поместите **содержимое этой папки** в корень репозитория, включая `.github/workflows/pages.yml` и `.nojekyll`. При работе через терминал скрытые файлы тоже должны попасть в коммит.
3. В Settings → Pages выберите Source → GitHub Actions.
4. Отправьте файлы в ветку `main`. Workflow Deploy game to GitHub Pages опубликует сайт. Если файлы уже отправлены, запустите его вручную через Actions.
5. После завершения возьмите HTTPS-адрес из Settings → Pages и проверьте запуск с телефона.

Все пути относительные: подходит и адрес вида `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`. Серверная часть не требуется. Не кладите токен Telegram-бота, пароли или секреты в репозиторий и клиентский код.

## Подключить Telegram

1. Создайте бота через официальный @BotFather, если его ещё нет.
2. В настройках бота настройте Main Mini App и укажите HTTPS-адрес опубликованной игры. При необходимости добавьте кнопку меню с тем же адресом.
3. Откройте приложение из бота и проверьте игру, кнопку возврата и облачное сохранение.

В обычном браузере игра тоже работает. Облако использует Telegram CloudStorage; при недоступности SDK прогресс остаётся локально. Перенос ручных слотов между устройствами выполняется через экспорт/импорт файла. Очистка данных браузера удалит локальные сохранения.

## Файлы

- `core.js` — состояния, отношения, условия и сюжетные переходы.
- `app.js` — интерфейс, сохранения, Telegram и звук.
- `data/story.json` — диалоги и каталог изображений.
- `assets/` — готовая графика.
- `styles.css` — вертикальная компоновка.
- `tests/story.test.js` — проверки финалов, ограничений романтики и сохранений.

Внутренний идентификатор `vera` сохранён для совместимости с графикой. В истории копия до раскрытия называется Валерка, затем Валерия. Настоящая Валерка остаётся Валеркой.

Внешние запросы: Telegram SDK и Google Fonts. При недоступности шрифтов используются системные. Игра не вызывает генераторы изображений или речи и не расходует токены при прохождении.

## Обновление 0.2 — понятный темп истории

Перед ключевыми эпизодами добавлены отдельные карточки места, времени и текущей задачи. За ними следуют повествовательные окна, объясняющие переход, состав участников и причины происходящего. Постановочные действия теперь читаются между репликами. Переходы к параллельным линиям и возврат во времени обозначены явно.

Название места под заголовком открывает «Где мы сейчас?» с вводной и задачей. При продолжении сохранения эта справка показывается перед возвращением к диалогу. Смена говорящего в групповой сцене больше не заменяет стоящий спрайт третьим персонажем. Старые сохранения остаются доступными; для новой общей завязки рекомендуется начать новую историю.
